# FYP_code

The flood-mapping pipeline for the Alaknanda corridor project. The project
description, study area, run order, data sources and status are in the
`README.md` one folder up.

This file replaces the August 2026 version, which described the retired
corridor (a 5 km buffer around seven anchor points, 808 km², "90 to 100 km").
The corridor in use since 16 September 2026 is 606.35 km² and about 121 km long.

**Start here:** `../docs/SETUP_RUNBOOK.md` for the environment, then
`../RUN ORDER.md` for every step in order. Every script has a copy-paste
command at the top. All the model results come from one launcher,
`RUN ALL MODELS.bat`.

`data/` and `outputs/` are written by the scripts and are not in the repository.
